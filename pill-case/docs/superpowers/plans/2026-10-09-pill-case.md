# Four-week click-dial pill case — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A parametric CadQuery script that generates print-ready STEP and STL files for the four-part pill case, with automated fit checks.

**Architecture:** One module, `pill_case.py`, holding a frozen `Params` dataclass, small solid-building helpers, one `make_*` function per part (all modelled in assembled position, z up, which is also print orientation), placement helpers for the moving parts, and a `main()` that exports. `tests/test_pill_case.py` checks geometry by boolean intersection of the parts in different poses.

**Tech Stack:** Python 3.12 in `.venv`, CadQuery 2.8, pytest.

**Spec:** `docs/superpowers/specs/2026-10-09-pill-case-design.md`

## Global Constraints

- Tablets up to 6 mm diameter x 3 mm thick.
- 28 pockets, Sunday first, clockwise seen from above.
- PLA, 0.4 mm nozzle, 0.2 mm layers, no supports: no unsupported downward face beyond 45 degrees.
- No hardware. (Deviation from spec rev 2: the spring plunger does not fit in a 5.2 mm base, so the day detent is two printed flex arms in the lid on a notched hub. Spec to be updated in Task 6.)
- Overall size at most 84 mm diameter x 13.5 mm tall.

## Review Focus

- Printer tolerance tighter or looser than the 0.2 mm assumed: clearances must be single named parameters, and the fit-test pieces must cover every sliding or snapping fit.
- Door pushed past closed: must stop, not fall out.
- Dial turned the wrong way or past locked: must hit a hard stop so labels stay aligned.
- Lid left between days: flex arms are loaded only then; at rest in a notch they must not touch the hub.
- Tablet thinner than expected: lid rests directly on the dividers, so there is no gap to migrate through.

## File structure

- `pill_case.py` — parameters, helpers, parts, placement, export.
- `tests/test_pill_case.py` — geometry tests.
- `out/` — generated STEP and STL (not hand-edited).

## Key dimensions (all `Params` fields)

| Item | Value |
|---|---|
| Wall top `H` | 5.2 (floor 1.2 + pocket 4.0) |
| Pocket ring | r 32.2 to 39.2, dividers 1.0, floor fillet 1.0 |
| Base radius | 40.8 |
| Hub sprocket | r 14.0, 28 V-notches 0.8 deep, z 5.2 to 8.9 |
| Post | r 6.0, z 8.9 to 12.7, two lugs to r 7.5, 1.5 mm flex slot |
| Lid | thin zone 1.2 thick; thick zone r < 19.5 and rim r 39.7 to 41.6, both 3.4 thick; bore r 14.2 |
| Flex arms | two, 1.8 thick, about 18.7 long, nubs at 0 and 180 degrees |
| Door | 9.4 wide, 12 long, 2.0 thick, travel 8.0, closed at y 27.5 to 39.5 |
| Door latch | bump 0.5 high on lid at y = 30; channel 0.6 deep under door with a 0.45 tooth |
| Dial | r 30, z 8.9 to 12.7, bayonet twist 60 degrees |
